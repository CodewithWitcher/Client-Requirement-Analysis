Pricing Quick Reference Guide

Fast-reference pricing guide for full-stack client engagements covering pricing formulas, cost ranges, key drivers, technology recommendations, and common pitfalls for both Website and Mobile App projects.

Covers: 🌐 Website / Web App  |  📱 Mobile Application

🎯 What This Module Does

🌐 Website

A complete toolkit for pricing website projects, from landing pages to complex web applications and e-commerce platforms. Covers discovery, estimation, proposal, and delivery.

📱 Mobile Application

A complete toolkit for pricing mobile app projects (iOS, Android, Cross-Platform). Covers discovery, estimation, proposal generation, and project execution.

📊 4-Phase Workflow

1. Discovery → Use Client Questionnaire during meeting
2. Estimation → Map requirements to Pricing Parameters
3. Proposal → Generate formal proposal with quote
4. Development → Follow Project Checklist to launch

📱 Application Additional:

  1. Proposal → Generate formal proposal document
  2. Execution → Follow Project Checklist for delivery

💰 Quick Pricing Formula

🌐 Website

Base Calculation:

1. Base Cost = (Pages × Page Cost) + Features
2. Design Cost = Custom designs + branding
3. E-Commerce Cost = Platform + features (if applicable)
4. Infrastructure = Domain + Hosting + SSL + Database
5. Integrations = Sum of third-party integrations
6. SEO Cost = On-page SEO + optimization
7. Subtotal = Sum of all above
8. Final = Subtotal × Tech Multiplier × Complexity × (1 + Profit %)

📱 Mobile Application

Base Calculation:

1. Base Cost = (Screens × Screen Cost) + Features
2. Platform Cost = Base × Platform Multiplier
3. Design Cost = Screen Designs + Custom Elements
4. Backend Cost = API + Database + Hosting
5. Testing Cost = Development × 15-25%
6. PM Cost = Development × 10-15%
7. Subtotal = Sum of all above
8. Final Price = Subtotal × Complexity Multiplier × (1 + Profit %)

⚙️ Technology Recommendations

🌐 Website

For Most Projects:

  • CMS: WordPress (easiest for clients)
  • Hosting: Shared or VPS (based on traffic)
  • Design: Template + customization (fastest)
  • Database: MySQL (standard)

For E-Commerce:

  • Platform: WooCommerce (cost-effective) or Shopify (ease)
  • Payment: Stripe (global) or Razorpay (India)
  • Hosting: VPS or managed hosting

For Web Apps:

  • Stack: MERN or Laravel
  • Hosting: Cloud (AWS/GCP) with auto-scaling
  • Database: PostgreSQL or MongoDB
  • Design: Custom from scratch

For Budget-Conscious:

  • CMS: WordPress with free theme
  • Hosting: Shared hosting
  • Design: Template with minor tweaks
  • Plugins: Free alternatives where possible

📱 Mobile Application

For Most Projects:

  • Framework: Flutter (best balance of cost/performance)
  • Backend: Firebase (fastest development) or Supabase (more control)
  • Database: Cloud Firestore or PostgreSQL
  • Auth: Firebase Auth or Supabase Auth
  • Payments: Stripe (global) or Razorpay (India)

For Performance-Critical:

  • Framework: Native (Swift + Kotlin)
  • Backend: Custom API (Node.js/Django)
  • Database: PostgreSQL with caching

For Budget-Conscious:

  • Framework: React Native or Flutter
  • Backend: BaaS (Firebase/Supabase)
  • Database: Included with BaaS
  • Design: Template-based with customization

⚠️ Common Pitfalls

🌐 Website

❌ Underestimating content entry time
❌ Forgetting responsive design testing
❌ Not accounting for browser compatibility
❌ Ignoring hosting renewal costs
❌ Assuming "simple" means quick
❌ Not including admin training
❌ Forgetting email hosting setup
❌ Missing maintenance in quote
❌ Not clarifying domain ownership
❌ Underpricing e-commerce complexity

📱 Mobile Application

❌ Underestimating testing (should be 15-25% of dev time)
❌ Forgetting app store accounts and submission costs
❌ Not including backend infrastructure costs
❌ Assuming "simple" features are quick to build
❌ Not accounting for platform-specific requirements
❌ Ignoring maintenance and support costs
❌ Missing CI/CD setup costs
❌ Forgetting about device compatibility testing

💡 Pro Tips

🌐 Website

Save Costs:
- Use WordPress for standard sites (fastest, cheapest)
- Choose template + customization over full custom
- Use WooCommerce for e-commerce (vs custom)
- Let's Encrypt for SSL (free)
- Start with shared hosting, upgrade later

Add Value:
- Include basic SEO in every project
- Set up Google Analytics (free)
- Configure automated backups
- Provide admin training video
- Document everything

Quote Smart:
- Add 10-15% contingency
- Separate hosting/maintenance from dev
- Quote in phases (MVP → Full → Premium)
- Define revision limits clearly
- Charge for content entry separately

📱 Mobile Application

Save Costs:
- Choose cross-platform (Flutter/React Native) over dual native
- Use BaaS (Firebase/Supabase) instead of custom backend
- Start with MVP, add features in phases
- Use template designs with customization
- Implement analytics from day one (free)

Add Value:
- Offer CI/CD setup (shows professionalism)
- Include crash reporting (Firebase Crashlytics is free)
- Provide basic analytics dashboard
- Document the code thoroughly
- Offer training sessions for client

Quote Smart:
- Add 10-20% contingency for unknowns
- Separate maintenance from development
- Quote in phases (MVP → Full → Premium)
- Include revision limits in design
- Define scope clearly to avoid creep
